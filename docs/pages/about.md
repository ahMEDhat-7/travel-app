# About Page

## Overview
The about page (`/[locale]/about`) provides information about Sharm Cloud Tours company.

## Route
- `/en/about` - English about page
- `/ru/about` - Russian about page

## Content Sections
- Company mission
- Team information
- Why choose us
- Contact information

## Dependencies
- Uses `next-intl` for translations
