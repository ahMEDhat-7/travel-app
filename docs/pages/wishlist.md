# Wishlist Page

## Overview
The wishlist page (`/[locale]/wishlist`) displays user's saved tours.

## Route
- `/en/wishlist` - English wishlist page
- `/ru/wishlist` - Russian wishlist page

## Components
- Saved tours grid
- Remove from wishlist button
- Book now button

## Notes
- Requires authentication
- Uses localStorage for wishlist items

## File Location
`app/[locale]/wishlist/page.tsx`
